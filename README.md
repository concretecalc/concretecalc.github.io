# 건축콘크리트 허브

무료 콘크리트 계산기 — GitHub Pages용 정적 단일 페이지 사이트.

**사이트 주소:** https://concretecalc.github.io/

## 사이트 소개

건축 현장 기술자, 감리자, 공학도를 위한 한국어 원본 계산기 허브로, KS F 4009와 KCS 한국건설기준을 바탕으로 한다(60Hz 한국 현장 기준). 순수 HTML5, CSS3, 바닐라 자바스크립트 — 프레임워크, 빌드 단계, 백엔드가 없다.

## 계산기 (모두 클라이언트 측)

1. **콘크리트 소요량** — 순수 소요량, 손실률 반영 주문량, 레미콘 차량 대수(6 m³/대), 중량(2,400 kg/m³).
2. **철근 중량** — 단위 중량 = 지름² ÷ 162, 전체 길이, 전체 중량, 톤 환산. D10/D13/D16/D19/D22/D25.
3. **거푸집 면적** — 슬래브(한 면), 벽체(양면), 기둥(4면) 면적과 합판 소요 매수(1.22 m × 2.44 m).
4. **콘크리트 배합비** — 설계기준강도 18/21/24/27/30 MPa별 1 m³당 배합과 전체 재료량, 시멘트 포대 수(40 kg/포).
5. **타설 비용 산정** — 콘크리트 비용, 펌프카 비용, 인건비, 전체 타설 비용.

또한 설계기준강도별 표준 배합표, 6개의 콘크리트 실무 가이드, 자주 묻는 질문, 소개와 면책 조항을 포함한다.

## GitHub Pages 배포

1. GitHub 사용자 **motorwindinghub** 아래에 **concrete-hub**라는 공개 저장소를 만든다.
2. 이 폴더의 모든 파일(`index.html`, `README.md`, `.nojekyll`, `favicon.svg`, `guides/`)을 저장소 루트에 업로드한다. 단, 루트 사이트(motorwindinghub.github.io)의 프로젝트 사이트로 배포하는 경우에는 이 폴더 내용을 해당 저장소의 `concrete-hub/` 폴더에 넣는다.
3. 저장소에서 **Settings → Pages → Build and deployment → Deploy from a branch → branch `main`, folder `/ (root)` → Save**를 선택한다.
4. 몇 분 안에 **https://concretecalc.github.io/**에서 사이트가 열린다.

## 로컬 미리보기

```bash
python3 -m http.server 8000
# http://localhost:8000/ 열기
```

## 면책 조항

모든 계산 결과는 참고용 추정치이다. 실제 시공과 품질 관리는 설계도서, 시방서, 레미콘 공장의 배합설계서, 관련 법규와 기준을 따르고, 책임 기술자의 판단에 따라야 한다. 이 계산 결과를 근거로 한 시공에 대해 건축콘크리트 허브는 책임을 지지 않는다.
